# Emergent Self-Value Simulator

## Purpose
An interactive simulation of how specialized cognitive
modules interact to produce a unified, emergent state.

## Core modules
1. Semantic Memory
2. Affective Systems
3. Metacognition
4. Social Cognition

## Integration mechanisms
- Global Workspace
- Predictive Feedback
- Inter-module Connections

## Emergent outputs
- Modeled Self-Value
- Modeled Self-Trust

## Architectural principles
- No central domain-general reasoning module.
- Specialized modules maintain distinct responsibilities.
- Interactions and integration rules are inspectable.
- Users can adjust module activity and network connections.
- Outputs are computed model states, not psychological diagnoses.

## Initial implementation
Build a minimal, testable Python core before adding
the interactive user interface.

## Current status
- Four core module implementations are present.
- An aggregation-only integration layer combines the four module states for one stimulus.
- Automated unit tests: 28 passing, including seven integration tests.
- Global Workspace, Predictive Feedback, and Inter-module Connections are not implemented.
- Self-Value and Self-Trust calculations are not implemented.
- Interactive user interface is not yet implemented.
- Scientific validity and psychological interpretation are not established.
- The cognitive integration contract remains a draft and is not approved or frozen.
